🎨 Projeto Fundo Mágico

🚀 Projeto que utiliza Inteligência Artificial, n8n, HTML, CSS e JavaScript para gerar animações de background de forma automática.

O usuário informa o tipo de animação desejada e o sistema retorna todo o código necessário, pronto para uso, facilitando a criação de fundos animados para sites e aplicações web.

🧠 Como funciona

O usuário descreve o tipo de animação desejada

A solicitação é processada com apoio de IA

O sistema gera e entrega o código completo do background animado

🛠️ Tecnologias utilizadas

🤖 Inteligência Artificial

🔗 n8n

🌐 HTML

🎨 CSS

⚙️ JavaScript

🎯 Objetivo do projeto

Demonstrar a integração entre automação, IA e tecnologias web, tornando o processo de criação de animações de fundo mais rápido, acessível e produtivo.

📌 Referência

Projeto desenvolvido como parte da Semana do Zero ao Programador Contratado, promovida pelo canal Dev Em Dobro, utilizado como base de estudo e prática dos conceitos apresentados durante o evento.
